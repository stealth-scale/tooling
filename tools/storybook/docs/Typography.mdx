# Typography

Three families, which the theme names: one for text, one for a heading, and one for anything a
reader might retype, such as an identifier, a duration or a hash. A theme that names no heading
face sets headings in its text family, so a component reaches for `font-display` without
checking. The scale, the weights and the spacing below are the same in every theme, because a
product with a different rhythm is a different system rather than a different brand.

## Families

Each face set in itself, so the difference between two themes is on the page rather than in
their manifests. A theme brings its own files: the name beside a specimen is what the theme
asked for, and the specimen is what the browser drew, so a family that failed to load shows as
the fallback rather than as a name that lies.

## Scale

Every step comes with a line height paired to it. A component picks a step and never sets a
pixel size, which is what keeps two screens built by two people looking like one product.

<Scale />

## Weights

A variable font renders every weight from 100 to 900, which is exactly why a system has to say
which ones it uses. Semibold is the heaviest weight in running text; bold is for the single
word that has to win.

<Weights />

## Tracking

Letter spacing: tight for a heading, wide for the small capitals in a label. The default is
`tracking-normal`, and anything else needs a reason.

<Tracking />

## Leading

Line height for the cases the scale's own pairing does not cover: a heading that wraps, a
paragraph meant to be read slowly. The page shows it on enough text to wrap, because that is
the only place line height is visible.

<Leading />

## Monospace

For anything a reader might copy or compare character by character. It is not a decorative
choice: proportional digits make two numbers of the same magnitude look like different lengths.
