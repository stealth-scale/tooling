# Documentation

Start with the question you arrived with.

| I want to                                              | Read                                                       |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| Read configuration out of the environment              | [`@stealthscale/core-env`](../core/env/README.md)          |
| Pick the locale to answer a request in                 | [`@stealthscale/core-locale`](../core/locale/README.md)    |
| Report what a library did without choosing where       | [`@stealthscale/core-logging`](../core/logging/README.md)  |
| Answer with a success or a refusal instead of throwing | [`@stealthscale/core-result`](../core/result/README.md)    |
| Validate or parse a value at a boundary                | [`@stealthscale/core-schema`](../core/schema/README.md)    |
| Run the `stealth` command                              | [`@stealthscale/tool-cli`](../tools/cli/README.md)         |
| Configure a repository's toolchain                     | [`@stealthscale/tool-config`](../tools/config/README.md)   |
| Build a scratch workspace for a specification          | [`@stealthscale/tool-testing`](../tools/testing/README.md) |
| Follow the conventions every stealth repository shares | [docs.stealthscale.io](https://docs.stealthscale.io)       |
| Build, check and land a change here                    | [Contributing](../CONTRIBUTING.md)                         |

Design proposals, decisions and the roadmap of every stealth repository live in
[stealth-scale/docs](https://github.com/stealth-scale/docs); this repository holds none.
